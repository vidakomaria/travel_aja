# Custom Theme 2

Child theme untuk redesign Travel Aja. Data tetap dikelola melalui wp-admin dan struktur konten dari tema `custom-theme` tetap dipakai.

## Sumber konten beranda

- Hero: featured image halaman **Beranda**.
- Paket: menu **Paket Wisata**.
- Kendaraan: menu **Transportasi**.
- Review: komentar WordPress yang sudah disetujui.
- Artikel: menu **Posts**.
- Kontak: **Appearance → Customize → Kontak & Footer**.
- Teks hero: **Appearance → Customize → Beranda Custom Theme 2**.

Aktifkan melalui **Appearance → Themes → Custom Theme 2**.
